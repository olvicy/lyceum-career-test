# Пізнай себе. Відкрий можливості!

**Інтерактивне профорієнтаційне дослідження для учнів старших класів.**

Проєкт допомагає учням краще пізнати власні інтереси, схильності та вподобання, дослідити можливі освітні напрями й ознайомитися з профілями навчання Херсонського академічного ліцею імені О. В. Мішукова.

## Про проєкт

Інтерактив поєднує ігрові елементи, конструктор персонажа та дослідження професійних інтересів. Його мета — допомогти підліткам замислитися над власними здібностями й освітнім вибором.

Результати мають ознайомлювальний характер і не є психологічним діагнозом або остаточною рекомендацією щодо вибору професії.
